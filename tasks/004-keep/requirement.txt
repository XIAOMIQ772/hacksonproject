Reference image: ![image](./reference/home_page.png)\n\n**Type:** FOLDER\n**Dependencies:** None\n\n### REQ-1.1 Enter Website\n\nOpen the application and display the home page.\n\n**Type:** ATOMIC\n**Dependencies:** None\n\n**Scenarios:**\n\n- Enter Website\n  - **GIVEN:** User has a browser or app with network access.\n  - **WHEN:** Open the application entry URL.\n  - **THEN:** The home page is displayed.\n\n## REQ-2 Notes Management\n\nCore note management capability for listing, creating, updating, deleting, archiving, coloring, labeling, and pinning notes. Reference image: ![image](./reference/home_page.png)\n\n**Type:** FOLDER\n**Dependencies:** REQ-1\n\n### REQ-2.1 Note Listing\n\nDisplay the notes list on the home page with pinned notes shown separately from unpinned notes. Reference image: ![image](./reference/trash_list.png) The system contains a deletable regular note titled \"Delete me 2.3.3\".\n\n**Type:** ATOMIC\n**Dependencies:** REQ-2.3.1\n\n**Scenarios:**\n\n- Trash list\n  - **GIVEN:** User can see the sidebar.\n  - **WHEN:** Click the Trash item in the sidebar.\n  - **THEN:** The page displays the list of deleted notes.\n\n### REQ-2.4 Update Note\n\nEdit the content of an existing note and persist the updated note after the editor is closed.
